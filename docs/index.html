01 — Workspaces
1 / 5

To-dos and timetable

Plan the day in blocks, not lists.

Nested checklists grouped under headings, next to a calendar-style time-blocking grid. Park what isn't for today in the drawer, carry overdue work forward, and mark holidays and time off.

Notes and AI

Real markdown files. AI you review as a diff.

Live preview and a scroll-spy outline. Ask about any sentence and the answer stays beside it. AI edits scoped to a sentence, a section or the whole note arrive as a reviewable diff, and whole-note drafts write in the background.

Diagrams

Paste DDL, get an ERD you can actually read.

Mermaid .mmd files on a pan/zoom canvas. Search tables and columns, click one to focus it and its neighbours, and switch between two layout engines.

Database sync

Connect MySQL, get every schema drawn.

Amber reads information_schema in a read-only session and writes one deterministic ERD per schema without AI. When the live schema drifts, a banner shows the diff before anything is regenerated.

Daily and weekly reports

Your day, written as problem → fix.

At the end of the day the AI reads your to-dos, GitHub activity and local Claude Code or Codex sessions and writes the report. Weekly rolls the dailies up into Notion-ready text.

02 — On the side

And what the day taught you, kept.

When a chat teaches you something worth keeping, paste it and Amber turns it into a flashcard with a detail note. Three confidence dots and a “learned” state keep the deck down to what you haven't internalized yet, and an always-on-top widget cycles the weakest cards between tasks.

04 — Install

Distributed as source.
Built in one sitting.

  • macOS with the Xcode Command Line Tools
  • Rust toolchain via rustup
  • Node.js 20+ and pnpm
  • Optional: Claude Code or Codex CLI for AI features, gh for reports, a MySQL account for database sync

The first build compiles the Rust side and takes a few minutes. First launch detects the AI CLIs you have signed in. The app doesn't update itself: after a new release, git pull, build again, quit Amber and swap the app. Your data lives outside the app and stays put.
