The desk for your engineering day.

A desktop app for macOS. Plan the day in to-dos and time blocks, think it through in markdown notes, read every schema as an ERD synced from your database, and let AI write the day up. Local-first, on the Claude Code and Codex CLIs you already pay for.

01 — Workspaces
1 / 9

To-dos / Carry-over

Yesterday's leftovers, brought to today.

Unfinished work from earlier days waits in an Overdue strip at the top of today. Bring it all over in one click, or one item at a time. The original day keeps a faded record of what moved, and checking it there still completes it.

To-dos / Timetable

Plan the day in blocks, not lists.

Nested checklists grouped under headings, next to a calendar-style time-blocking grid. Drag to create a block with a 15-minute snap, park what isn't for today in the drawer, and mark holidays and time off.

To-dos / Daily report

Your day, written as problem → fix.

At the end of the day the AI reads your to-dos, GitHub activity and local Claude Code or Codex sessions and writes the report. Weekly rolls the dailies up into Notion-ready text.

Concepts

Turn a chat that taught you something into a card.

Paste the Q&A and Claude organizes it into a title, a summary and a detail note you can edit before saving. Three confidence dots and a learned state keep the deck down to what you haven't internalized, and the desktop widget cycles the weakest cards between tasks.

Notes / Ask

Drag a sentence, ask about it.

Select any passage and ask. The answer arrives in a thread beside the text, where you can follow up, and the passage keeps a highlight so the question is one click away later.

Notes / Write with AI

Write the note together.

Tell Claude what to cover, add a preset or a reference folder, and let it draft in the background while you keep working. When the draft is ready you review the changes and apply them to the editor; nothing is saved until you press ⌘S.

Notes / Edit a part

Real markdown files. Edits you review first.

Select a sentence or a section and say how it should change. Only that part is rewritten, shown against the original before it goes back into the draft.

Diagrams / ERD

Paste DDL, get an ERD you can actually read.

Mermaid .mmd files on a pan/zoom canvas. Click a table to light up its neighbours, open its columns in a side panel with keys and nullability, and switch between two layout engines.

Diagrams / Database sync

Connect MySQL, get every schema drawn.

Test the connection, pick the schemas, and Amber reads information_schema to write one deterministic ERD per schema without AI. The password stays in the macOS Keychain. When the live schema drifts, a banner shows the diff before anything is regenerated.

04 — Install

Distributed as source.
Built in one sitting.

  • macOS with the Xcode Command Line Tools
  • Rust toolchain via rustup
  • Node.js 20+ and pnpm
  • Optional: Claude Code or Codex CLI for AI features, gh for reports, a MySQL account for database sync

The first build compiles the Rust side and takes a few minutes. First launch detects the AI CLIs you have signed in. The app doesn't update itself: after a new release, git pull, build again, quit Amber and swap the app. Your data lives outside the app and stays put.
